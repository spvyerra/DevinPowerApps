# Plans

Every executed agentic plan for this repo lives here as one Markdown file.
Plans are written before implementation so the user can review them.
Unexecuted drafts and rejected versions are never committed.

## Naming

Name files `YYYY-MM-DD-<short-slug>.md`.
When an executed plan is followed by a new direction, add a new file with a `-v2` style suffix instead of overwriting the old one.

## Expected contents

1. Goal: one or two sentences on what the plan delivers.
2. Decisions: choices made with the user and the reason for each.
3. Scope: what is in, and what is explicitly out.
4. Design: file layout, data model, and flows, kept to what the steps need.
5. Steps: checkbox list grouped by phase, each with acceptance criteria.
6. Verification: how each phase is checked end to end.
7. Open questions: anything still waiting on the user.
8. Status log: dated lines recording progress and scope changes.

## Upkeep

Tick steps as they land and record scope changes in the status log, so the file stays an accurate record.
